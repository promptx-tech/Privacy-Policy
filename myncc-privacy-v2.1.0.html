7मैसेजिंग, E2EE और नोटिफिकेशन्सMessaging, E2EE and Notifications

  • 1-to-1 प्राइवेट चैट (E2EE): टेक्स्ट मैसेज EC P-256 + HKDF + AES-256-GCM से एंड-टू-एंड एन्क्रिप्टेड हैं; न Firebase, न डेवलपर इन्हें पढ़ सकते हैं। आप 60-अंकों के Safety Code से एक-दूसरे की सुरक्षा सत्यापित कर सकते हैं।1-to-1 private chat (E2EE): Text messages are end-to-end encrypted with EC P-256 + HKDF + AES-256-GCM; neither Firebase nor the developer can read them. You can verify each other’s security with a 60-digit Safety Code.
  • E2EE की-बैकअप: आप अपनी E2EE प्राइवेट कुंजी का पासफ्रेज-संरक्षित एन्क्रिप्टेड बैकअप (PBKDF2, 250,000 iterations) सर्वर पर सेव कर सकते हैं।E2EE key backup: You can save a passphrase-protected encrypted backup of your E2EE private key on the server (PBKDF2, 250,000 iterations).

चेतावनी: हम आपकी पासफ्रेज स्टोर नहीं करते। पासफ्रेज भूलने या बिना बैकअप फोन बदलने पर पुरानी चैट रिकवर नहीं हो सकेंगी।Warning: We do not store your passphrase. If you forget it or change phones without a backup, old chats cannot be recovered.
