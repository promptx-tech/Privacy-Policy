1Unofficial & Independent Application

“My NCC: Cadet Management Ecosystem” is an independent, privately developed utility application designed to assist cadets with their daily administration, attendance, and routines.

2Purpose of the App

This app operates strictly as a private management and utility tool. It provides features like QR-based attendance, PIN authentication, and PDF form generation to digitize local unit tasks. It does not represent any government entity and should not be considered an official military or government software.

3Data Security & Cloud Storage

We prioritize user privacy with the highest security standards:

  • Military-Grade Encryption: All sensitive data is secured using AES-256-GCM encryption before being transmitted.
  • Private Servers: Data is synchronized using Firebase/Firestore and GitHub private repositories configured by the developer. No data is stored on or transmitted to any official government servers.
  • Zero-Knowledge Architecture: The data is deeply encrypted in such a way that even the developer cannot read or access the personal records stored on the server.
